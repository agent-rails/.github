# Support

Use the target repository's issue tracker for reproducible bugs, feature proposals, and documentation problems. Search existing issues before opening a new one and include the smallest useful reproduction.

General design questions should use repository discussions when enabled. Otherwise, open a clearly labeled question issue.

Security vulnerabilities must follow the private process in [SECURITY.md](SECURITY.md), not the normal support path.

Agent Rails projects are maintained on a best-effort basis. Response times are not guaranteed.
